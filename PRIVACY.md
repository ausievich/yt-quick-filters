# Privacy Policy

YouTrack Quick Filters is a browser extension that adds reusable quick filters to YouTrack Agile boards.

## Data stored on the device

The extension stores quick filters and preferences in the browser's extension storage. To make authenticated YouTrack API requests, it may also store the access token obtained from the active YouTrack session. This data remains on the device and is not transmitted to the developer or to any third party.

## Anonymous usage analytics

The extension sends limited, anonymous usage analytics to [PostHog](https://posthog.com/) to understand which features are used and to improve the extension. These events include a randomly generated installation ID, the extension version, feature actions, aggregate filter counts, and non-sensitive settings such as the selected color theme.

The extension does **not** send filter names or queries, YouTrack URLs or domains, projects, issues, users, access tokens, or the content of YouTrack pages to PostHog. IP addresses and other connection metadata may be processed by PostHog to receive requests, under [PostHog's Privacy Policy](https://posthog.com/privacy).

## Sharing and retention

Analytics data is shared only with PostHog, the analytics service provider. User data is not sold and is not used for advertising. Analytics data is retained only as long as needed to improve and maintain the extension.

## Contact and data removal

Locally stored data is removed when the extension is uninstalled via the browser's extension settings. Privacy questions and requests can be raised by opening an issue at [github.com/ausievich/yt-quick-filters](https://github.com/ausievich/yt-quick-filters/issues).
